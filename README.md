# 🐞 Jogo Educativo: Adivinhe os Insetos!

Este projeto consiste em um jogo educativo e interativo desenvolvido com o objetivo de ensinar, de forma divertida, sobre diferentes tipos de insetos, suas características e sua alimentação.

O jogo possui **duas fases**, nas quais o jogador pode testar seus conhecimentos e aprender curiosidades sobre a natureza.

## 🌱 Fase 1 – Adivinhe o Inseto!

Na primeira fase, o jogador precisa identificar diferentes insetos por meio de imagens e alternativas de respostas.

- São 10 perguntas sobre diferentes insetos.
- Cada resposta correta soma pontos.
- Ao responder, o jogador recebe uma mensagem informando se acertou ou errou.
- Também são apresentadas curiosidades sobre cada inseto.
- Ao finalizar as perguntas, o jogador visualiza sua pontuação.

## 🌻 Fase 2 – Alimente os Insetos!

Na segunda fase, o jogador precisa relacionar cada inseto ao seu alimento correspondente, arrastando os alimentos até o inseto correto.

- A lagarta deve receber uma folha.
- A borboleta deve receber néctar.
- A abelha deve receber mel.
- A joaninha deve receber pulgões.
- O jogador recebe mensagens de acordo com suas respostas.
- Ao completar todos os desafios, aparece uma mensagem de conclusão.

## 🎮 Funcionalidades

- Duas fases com desafios diferentes.
- Sistema de pontuação.
- Mensagens de acerto e erro.
- Curiosidades educativas.
- Interação por meio de botões e elementos arrastáveis.
- Possibilidade de jogar novamente.
- Interface colorida e intuitiva.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo do projeto

O objetivo é unir tecnologia e educação ambiental, proporcionando uma experiência divertida e acessível para aprender mais sobre os insetos e sua importância para a natureza.

O projeto foi desenvolvido como uma forma de praticar programação e criação de interfaces interativas, além de incentivar o conhecimento e a preservação do meio ambiente.

🌿 **Aprender sobre a natureza também pode ser divertido!**
